# SACRED TAG FIGHT — ONLINE

실시간 2인 온라인 대전용 Node.js + Socket.IO 프로젝트입니다. CPU 상대는 없습니다.

## 실행
1. Node.js 18 이상 설치
2. 프로젝트 폴더에서 `npm install`
3. `npm start`
4. 브라우저에서 `http://localhost:3000` 접속

같은 PC에서 테스트할 때는 브라우저 창/기기를 두 개 열어 방 생성과 참가를 시험할 수 있습니다.

## 인터넷에 배포
Node.js 웹서비스를 지원하는 호스팅(Render, Railway 등)에 이 폴더 전체를 업로드하고 빌드 명령 없이 시작 명령 `npm start`를 설정하세요. 배포된 HTTPS 주소를 친구와 공유하면 됩니다. 서비스가 실행 중이어야 온라인 접속이 됩니다.

## 조작
A/D 이동, W 점프, S 또는 L 방어, J 약공격, K 강공격, U/I 스킬, ; 태그.
화면 버튼도 제공됩니다.

## 참고
이 프로젝트는 온라인 방 생성/참가, 2인 소켓 연결, 실시간 위치/전투 상태 전달이 포함된 실행 가능한 출발 버전입니다. 기존 인라인 프로토타입의 모든 애니메이션/밸런스/개별 스킬 연출을 그대로 옮긴 완성 상용 게임은 아닙니다. 현재 전투 판정은 서버 측 간단 프로토타입이며, 실제 공개 서비스 전에는 입력 검증, 재접속 처리, 지연 보정, 방 만료, 치트 방지, 테스트가 필요합니다.
